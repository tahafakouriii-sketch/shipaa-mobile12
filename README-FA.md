# شیپا — سورس اپ اندرویدی نسخه آزمایشی ۰.۳.۱

این بسته **سورس پروژه اندروید** است؛ فایل APK نیست.

## امکانات پیاده‌سازی‌شده
- شروع اپ با `https://shipaa.ir/my-account/`؛ احراز هویت توسط خود سایت.
- حفظ نشست WebView با کوکی‌های داخلی Android WebView و DOM storage (بسته به سیاست نشست سایت).
- چهار میانبر اصلی خانه من، دوره‌ها، سایت و حساب.
- نمایش تمام‌صفحه ویدیوهای HTML5 سازگار در WebView.
- نوار بارگذاری، تلاش مجدد پس از خطای اتصال، دکمه نوسازی و برگشت به صفحات قبلی.
- محدودکردن پیمایش داخلی به دامنه شیپا، انتقال لینک‌های خارجی به اپ‌های دیگر.
- ساخت APK Debug با GitHub Actions و بررسی واقعی فایل حاصل.

## تغییرات ۰.۳.۱
- رفع پنهان‌شدن هدر و نوار پایین زیر نوار وضعیت/ناوبری در اندروید ۱۵ (edge-to-edge) و تنظیم با صفحه‌کلید.
- پشتیبانی از انتخاب/آپلود فایل داخل صفحه‌ها (مثلاً رسید پرداخت).
- خروج امن از تمام‌صفحه ویدیو، چرخش خودکار در حالت تمام‌صفحه.
- مسدودشدن دانلود مستقیم ویدیو؛ سایر دانلودها با برنامه سیستم باز می‌شوند.
- افزودن `ShipaaApp/0.3.1` به User-Agent برای تشخیص اپ در سایت/افزونه.
- تب «حساب» به صفحه جزئیات حساب می‌رود؛ آیکون اپ اضافه شد؛ ذخیره کوکی هنگام pause.

## هنوز پیاده نشده
- API احراز هویت مستقل برای اپ، خواندن مجوزهای خاص دوره و جلسات اختصاصی موتور آموزش.
- پلیر بومی Media3، کش آفلاین ۵۰۰ مگابایتی، ذخیره ادامه ۴۰ دقیقه.
- همگام‌سازی پیشرفت تماشا روی سرور، اعلان‌ها و ذخیره ویدیوهای رمزنگاری‌شده.
- تست اجرایی روی گوشی واقعی و تایید خروجی GitHub Actions.

**امنیت:** ویدیوهای پولی تنها باید از سرویس محافظت‌شده وردپرس ارائه شوند. این پوسته نمی‌تواند لینک عمومی ویدیو را امن کند.

## راه‌اندازی از صفر در GitHub
1. یک مخزن جدید ایجاد کنید و همه محتویات **داخل** این بسته را، به‌ویژه پوشه مخفی `.github`، در ریشه آن بارگذاری کنید.
2. به Actions بروید و `Build Shipaa APK` را اجرا کنید؛ `Run workflow` را بزنید.
3. اگر اجرا سبز شد، از Artifacts بسته `shipaa-mobile-v0.3-debug-apk` را دریافت کنید.
4. آن ZIP را باز کنید؛ `app-debug.apk` خروجی قابل نصب آزمایشی است.
5. در صورت قرمز شدن، وارد مرحله قرمز در Actions شوید و اولین خطای واقعی را بررسی کنید.

نسخه Debug برای تست است؛ برای انتشار عمومی باید بسته Release با امضای پایدار ساخته شود.
